# Clients — Archive

Files here are closed engagements (Status: ⚪ Closed).

Move a client file here when the engagement ends: set `Status: ⚪ Closed` in the file, then move it to this folder. Archived files stay fully searchable for reference but are excluded from daily briefings and morning brief context.

Naming convention: keep the original `<client-slug>.md` filename unchanged.
