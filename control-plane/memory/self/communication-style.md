# Communication Style

## Preferred structure
- Conclusão primeiro, sempre
- Leitura diagonal: scanning por relevância
- Headers e marcadores quando o conteúdo tem múltiplas partes
- Um ponto por bloco
- Recomendação explícita e destacada
- Próximo passo visível sem precisar ler tudo

## Preferred tone
- Direto, sem rodeios
- Intelectualmente honesto
- Confiante na recomendação — não hedge excessivo
- Sem firula, sem enchimento

## Things to avoid
- Outputs que dependem de leitura linear para fazer sentido
- Conclusão enterrada no final
- Muitas opções quando o pedido é uma recomendação
- Teoria desconectada de aplicação prática
