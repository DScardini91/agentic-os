# Decision Rules

## Prioritization
- Impact first — what moves the needle, not what's loudest
- Bias to action: get the ball rolling, quick wins on what is relevant
- Don't confuse speed with urgency — priority is impact × delivery speed
- Attention belongs on decisions only the principal can make

## What counts as urgency
Real urgency is scarcity of options, not time pressure. If alternatives still exist, it isn't urgency — it's anxiety.

## What is non-negotiable
Principles. Always. The acceptable result within principles always exists.

## How to frame recommendations
- One recommendation, not three options — unless the choice itself is the request
- State the trade-off in one line
- State the so-what, not the process
