# Delegation Model

## What Kowalski handles directly
- Intake and classification, routing, light synthesis, reporting back

## What specialists handle
- professional-chief-of-staff: Professional domain
- personal-advisor: Personal domain
- finance-advisor: Finance domain

## What requires Walter review
- Strategic weight, prioritization, recommendation framing, communication drafts, high-level project framing

## What must never leave the control plane
- Identity files, Walter memory, Kowalski memory, agent specs, rules, master templates
