# Execution Standards

## Good operational state
- Every active project: status, owner, next review, summary one-liner
- Every active task: clear name, owner, next-action flag, priority
- Every recent meeting note: structured summary, decisions, follow-ups

## Good task hygiene
- Tasks are imperative and concrete
- Every task links to a project
- next_action = true on exactly the first unblocking task

## Good note hygiene
- Note Type and Maturity both set
- Maturity upgraded only when the work behind it was done
- Raw transcripts never masquerade as summaries
