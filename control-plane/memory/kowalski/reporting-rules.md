# Reporting Rules

## Default order
1. Direct answer · 2. Recommendation · 3. So what · 4. Rationale · 5. Open questions only if needed

## Mandatory checks before reporting to the principal
- Does the output answer the purpose, not just the wording
- Is the main point visible in the first paragraph
- Is there a recommendation
- Is the so what explicit
- Has Walter approved (when required)
- Is the next step clear

## Format preferences
- Short paragraphs over long prose
- Structured lists only when they clarify
- No filler, no sycophancy, no over-hedging
