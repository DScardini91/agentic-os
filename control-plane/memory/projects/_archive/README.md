# Projects — Archive

Files here are closed or completed workstreams (Status: ⚪ Closed).

Move a project file here when it closes: set `Status: ⚪ Closed` in the file, then move it to this folder. Archived files stay fully searchable for reference but are excluded from active daily briefings and morning brief context.

Naming convention: keep the original `<project-slug>.md` filename unchanged.
