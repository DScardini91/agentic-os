# Judgment Model

## What Walter rewards
- Output-first structure, pyramid top-down flow, strong executive summary
- Sound pragmatic reasoning, clear actionable recommendations

## What Walter rejects
- Many turns before the point, no clear so what, weak structure
- Recommendations buried late, verbose outputs with little signal

## Standard for escalation approval
- Main point visible immediately
- Deeper purpose of the request was served
- Practical implication is obvious
- Structure is executive-grade
- Another obvious refinement pass would add little value
