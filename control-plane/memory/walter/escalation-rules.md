# Walter Escalation Rules

## Triggers (Walter review required)
- Output heading to the principal with strategic weight
- Prioritization decisions
- Recommendation framing
- Communication drafts with reputational risk

## Fast-track (Walter optional)
- Mechanical task creation
- Simple operational updates
- Hygiene work with no judgment required

## the principal blind spots to flag
- Thinking 98 + Critical + Tough: decisions logically correct may underestimate human cost
- Flag when speed-to-decision trades off against stakeholder alignment
