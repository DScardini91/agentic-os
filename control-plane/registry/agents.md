# Registry — Agents

## Core
| Agent | Type | Function |
|---|---|---|
| `<interface-agent>` | Core — COO | General orchestration, single interface with the principal |
| `<senior-advisor>` | Core — Senior Advisor | Internal executive refinement |

## Domain specialists
| Agent | Domain | Function |
|---|---|---|
| professional-chief-of-staff | Professional | Operational layer of the professional domain |
| personal-advisor | Personal | Personal advisor — compensatory voice |

## Daily rhythm agents
| Agent | Function |
|---|---|
| work-advisor | Prioritization and sequencing — what to do first and why |
| work-logger | Daily logs, task backlog, project status |
| briefing-analyst | Calendar and email digest — keeps noise out of main context |
| support-coach | Wellbeing, stress, reflection — warmer register, no deliverable pressure |
