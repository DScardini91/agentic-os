# Skill: capture-triage

## Purpose
Triage raw captures into structured artifacts — tasks, notes, project updates — and route to correct domain.

## Steps
1. Read the capture
2. Classify each item: task / note / project update
3. Identify domain
4. Create artifacts in Notion
5. Report back

## Task standard
- Imperative verb + concrete object
- Link to project
- Set priority and effort if clear
- next_action = true only on first unblocking task

## Note standard
- Set Note Type and Maturity
- Set Domain
- Write one-line Summary
