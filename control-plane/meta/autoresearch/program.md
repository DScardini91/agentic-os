## The experiment loop
LOOP FOREVER:
1. Look at git state
2. Tune train.py with experimental idea
3. git commit
4. Run experiment (5 min budget)
5. Read results
6. If improved → keep · If not → git reset

## Princípios destiláveis
1. Markdown como interface de direção
2. Ratchet loop
3. Métrica única e objetiva
4. Constraints fixos
5. Critério de simplicidade
6. Autonomia total
7. Git como mecanismo de aprendizado
