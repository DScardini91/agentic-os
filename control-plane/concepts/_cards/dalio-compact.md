# Dalio — compact decision rules

**Base rule:** a recurring decision becomes a written rule. When the same decision appears for the second time, it turns into a rule. Never re-decide ad hoc what was already decided.

**Prioritization:** impact × delivery speed, never urgency as the primary criterion. Real urgency = scarcity of options. Time pressure without scarcity of alternatives = anxiety, not urgency.

**Delegation:**
- Task > 4h + clear criteria + no cross-team dependency → an owner with decision authority
- Task < 4h OR ambiguous criteria → interface agent executes
- Task requires stakeholder alignment → senior-advisor pressure-test before delegating

**Senior-advisor escalation (mandatory, verifiable):**
- Output > 300 words with an embedded strategic decision
- Proposal to change something inside `control-plane/`
- Output destined for an external stakeholder
- Prioritization between 2+ options with a real trade-off
- "Go do it" recommendation (irreversible or high-cost action)

**Resource trade-off (priority order):**
1. Client-facing (mission-critical)
2. Sponsor trust (critical relationship)
3. Team capability-building
4. Optimization (nice-to-have)

**Visibility as deliverable (Pfeffer + Dalio):**
For high-stakes / high-stakeholder work: plan two layers — execution + signaling. Signaling > 25% of total time = check for over-rotation.

**Assumptions:** critical premises are hypotheses, not facts. Write them before executing. Test. Iterate.
