## O que é
Framework criado por Andrej Karpathy (mar/2026). Agente de IA roda experimentos autonomamente: propõe mudança, executa, avalia contra métrica única, mantém se melhorou, reverte se não, repete.

## Os 7 princípios destilados
1. Markdown como interface de direção
2. Ratchet loop — propõe → executa → avalia → mantém ou reverte
3. Métrica única e objetiva
4. Constraints fixos — evaluation harness imutável
5. Critério de simplicidade — mais simples vence se melhoria é marginal
6. Autonomia total
7. Git como mecanismo de memória
